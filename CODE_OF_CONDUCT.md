# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## Summary

We commit to providing an open, welcoming, harassment-free community, regardless of age, disability, background, identity, experience, nationality, or beliefs.

Expected behavior: show empathy, respect differing opinions, offer constructive criticism, take responsibility for mistakes, and put the community before yourself.

Unacceptable behavior: harassment, discriminatory or insulting remarks, personal attacks, publishing others' private information without consent, and any conduct reasonably considered inappropriate in a professional setting.

## Enforcement

Maintainers may moderate, edit, or remove any content or contribution that violates this code, and exclude its author. Report incidents through a private security advisory in the repository (Security tab) or by contacting the maintainers using the contact listed on the repository profile. All reports are handled confidentially.

The full, authoritative text is at the link above (CC BY 4.0 license).
